# Plugin & skill authoring rubric (micky-psych-tools + learn-hub)

Basis: phase-1 evidence in `scratchpad/wf1/`. Only claims with verdict `confirmed` or `partially` are used; `partially` claims are used in their `corrected_claim` wording. Refuted claim LOC-26 is not used. Date: 2026-09-23, Claude Code 2.1.280.

**Legend**
- **Sources.** `SKL-/PLG-/EVL-/COM-/LOC-nn` are research claim ids. `MP-XXX-n` are verifier `missed_practices` (n = position in that file). `INV:<unit>-<n>` is an inventory defect (unit name + defect index, from `inventory-*.json`). `OBS` is an orchestrator observation from this session.
- **Enforcement.** `claude-plugin-validate` = `claude plugin validate --strict`. `house-validator` = repo script. `plugin-eval` = `claude plugin eval`. `review` = a human or agent reads it.
- **Level.** MUST = fails acceptance. SHOULD = deviation needs a one-line reason in the plugin README.
- **Profiles.** Every skill declares `metadata.profile: cc | portable`. `cc` means Claude Code only (Claude Code-only frontmatter allowed). `portable` means it must also load on claude.ai upload or the Skills API (R54).
- **House numbers.** Thresholds marked *(house)* are chosen here. No source states them.

## A. Discovery (name, description, when_to_use, listing budget, collisions)
