Everything on this page is computed live in your browser by the three implementations in this file — a symbolic differentiator (sum/product/quotient/power/chain rules + constant folding) over an expression DAG, finite differences, and forward-mode automatic differentiation with dual numbers. No values are stored or drawn by hand. Seed — drives the self-check probe points; the same seed reproduces this run. Scale caveat: forward-mode AD on one scalar input. Production frameworks (JAX, PyTorch) use reverse mode, which gets all n parameter-derivatives in one backward sweep instead of n forward sweeps — same chain rule, opposite direction. Costs are counted primitive operations, not milliseconds: browser timings are noise.
