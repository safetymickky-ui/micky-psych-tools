Run the `plan-critique` skill now.

- `$ARGUMENTS` names the plan — pasted text that follows, a file path, or a vault
  artifact → critique that.
- `$ARGUMENTS` empty → critique the plan most recently shown or produced in this
  session. If no plan exists, say so and ask for one — never invent a plan to critique.

The skill owns the whole procedure — resolve the plan → yardstick → nine lenses →
triage repairs vs forks → relentless batched option-picker interview → verdict-first
critique + the full revised plan under a decision ledger. This command is only the
manual trigger for it.
