  1. Step 1 — Module evaluated (lines 1-6). The file is evaluated top to bottom. DEFAULT_BASE_MS and DEFAULT_CAP_MS are bound; nothing is called yet.
  2. Step 2 — sleep is bound, its body not run (line 7). Line 7 binds the arrow function to sleep. Its body — the new Promise on lines 8–18 — does not run here. Watch for it at step 10.
  3. Step 3 — A caller invokes withRetry (lines 20-27). The function is entered and the options bag is destructured: retries 3, baseMs 200, capMs 10000, signal undefined for this trace.
  4. Step 4 — lastError declared outside the loop (lines 28-29). let lastError; creates one error slot in the function body scope, outside the loop below.
  5. Step 5 — Loop init: attempt = 0 (line 30). The initialiser runs once. 0 <= 3 is true, so the body is entered for the first of up to four passes.
  6. Step 6 — Abort check, before the try (lines 31-32). signal?.throwIfAborted(). With no signal in this trace ?. short-circuits. Had the caller aborted, the throw would leave withRetry right here.
  7. Step 7 — await operation(0) suspends (lines 33-34). Control leaves the function and returns to the event loop. In this traced run the operation rejects; had it resolved, the return would end everything here.
  8. Step 8 — Caught: record, then test for break (lines 35-38). lastError = error. Then attempt === retries is 0 === 3 → false, so no break: fall through to the backoff.
  9. Step 9 — Backoff: ceiling 200 ms (lines 39-40). ceiling = Math.min(10000, 200 * 2 ** 0) = 200. Then sleep(Math.random() * 200) is called — and awaited.
  10. Step 10 — Now sleep's body runs (lines 8-18). Source order and execution order part company here. Bound at line 7, entered at step 10: the timer is armed, the abort listener is attached, and the promise stays pending until one of them fires.
  11. Step 11 — Back-edge: attempt++, re-test (lines 41-43). The catch and the loop body close. attempt becomes 1, 1 <= 3 holds, and control jumps back to line 30. Attempts 1 and 2 repeat steps 5–10 with ceilings 400 and 800.
  12. Step 12 — Budget spent: rethrow (lines 44-45). On attempt 3 the catch runs 3 === 3 → break, so no fourth wait is computed. The loop is exited and the last error recorded is thrown to the caller.
