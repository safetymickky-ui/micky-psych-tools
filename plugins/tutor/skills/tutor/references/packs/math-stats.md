## Anchors

- **Gradient descent** → Rescorla–Wagner: V ← V + α(λ − V) is one gradient step on ½(λ − V)² with step size α. Breaks: with α ≤ 1, RW never overshoots a single cue; ML losses couple many weights, and a step too large for the curvature diverges (ms-6.2).
- **Dot product** → the linear predictor xᵢᵀβ in glm(). Breaks: the dot product also measures angle (Pearson r is the cosine of centred vectors), which regression output never shows.
- **(XᵀX)⁻¹** → lm() returning NA for an aliased predictor. Breaks: near-collinearity fails silently, with a tiny det(XᵀX) and exploding SEs; ridge's + λI is the repair.
- **Hessian, observed information** → vcov() and the Std. Error column. Breaks: on a flat ridge or at a boundary the curvature-based SE means nothing, e.g. the SE of a variance near 0.
- **Fisher information** → inverse-variance weights in meta-analysis (weight = 1/SE²). Breaks: with many parameters I is a matrix, and its off-diagonal terms (correlated estimates) change each SE.
- **LR, Wald, score** → anova(m0, m1), the z value in summary(), and anova(fit, test = "Rao"). Breaks: they agree only when ℓ(θ) is close to a parabola; small n or p̂ near 0 or 1 pulls them apart (ms-5.3, ms-5.4).
- **Priors as penalties** → ridge = MAP under Normal(0, τ²) priors with λ = σ²/τ²; LASSO = MAP under Laplace priors. Breaks: the full posterior under a Laplace prior has no exact zeros; sparsity exists only at the mode.
- **PCA** → scree plots and factor analysis in scale development. Breaks: PCA has no error term and no latent cause; loading signs are arbitrary; covariance PCA depends on units (ms-2.6).
- **Covariance matrix Σ** → VarCorr() in lme4. Breaks: VarCorr prints SDs and r while papers write variances and covariances; an SD of 0 or r = ±1 makes Σ singular, the "boundary (singular) fit".
- **Boundary χ² mixture** → a one-sided test: a variance can only move up from 0, so half the null LR mass sits at 0 and the naive p is twice too large. Breaks: adding a random slope plus its covariance needs ½χ²₁ + ½χ²₂, not simple halving.
- **Partial pooling (BLUPs)** → the Beta–Binomial posterior mean pulled toward the prior mean. Breaks: lme4 plugs in the estimated variance (empirical Bayes) and ignores its uncertainty; a full Bayesian fit averages over it.
- **AIC** → k-fold CV, since AIC approximates leave-one-out predictive deviance. Breaks: that needs large n and a roughly right model; BIC approximates −2 × log marginal likelihood, so it targets model choice, not prediction.
- **MCMC acceptance ratio** → Bayes in odds form: prior ratio × likelihood ratio of proposal vs current, with p(y) cancelling. Breaks: for continuous θ these are density ratios, and an asymmetric proposal needs the Hastings correction.
- **ELBO** → "variational free energy" F in active-inference and HGF papers: F = −ELBO. Breaks: same quantity, opposite sign; they minimize F, ML papers maximize the ELBO.
- **VI's reverse KL** → his forward vs reverse KL work: VI minimizes KL(q‖p), which is mode-seeking, so q comes out too narrow (ms-7.6). Breaks: expectation propagation uses the forward direction and spreads q out instead.

## Common errors and notation collisions

- **Prime ′** → f′(x) is a derivative, but V′ in learning models is "the updated V", p′ in Rethinking is "one particular value of p", and X′X in many stats texts is XᵀX; ask what wears the prime: a function, a quantity, or a matrix.
- **Superscripts** → x² is a power, but x⁽ⁱ⁾ (case i) and θ⁽ᵗ⁾ (step t) are labels, usually in brackets; Σ⁻¹ is an inverse and Aᵀ a transpose, while a plain T can also be the last time step.
- **Hat, bar, star, tilde** → β̂ is an estimate and ŷ a prediction, but R̂ in MCMC output is a convergence check and â in geometry (and math-as-code) is a unit vector; x̄ is a mean but Ā is "not A"; θ* is the minimizer in MML but the true value in PML1 §4.7.2 (and a proposal in MCMC); x̃ is "changed or approximate"; read the first use.
- **Bars and the semicolon** → p(y | x) "given", |x| absolute value, |A| determinant, |S| number of elements, ‖x‖ a norm; p(y; θ) marks θ as a fixed parameter and p(y | θ) as random, with the same algebra.
- **Greek letters with many jobs** → σ is an SD but σ(z) the logistic sigmoid; Σ with limits is a sum but a stand-alone Σ a covariance matrix; λ can be an eigenvalue, the glmnet penalty, a Lagrange multiplier, a Poisson rate, or the RW asymptote; α a learning rate, the significance level, a Beta shape, or Cronbach's α; fix each meaning at first use.
- **Index base** → maths and R count from 1, Python from 0: Σᵢ₌₁¹⁰⁰ i = 5050, but Python sum(range(100)) = 4950 (the Python version of math-as-code makes exactly this slip); write range(1, n + 1).
- **Normal's second slot** → papers write N(μ, σ²) with a variance; R rnorm(), scipy.stats.norm and Stan normal() take the SD; JAGS dnorm() takes the precision 1/σ²; "N(0, 4)" can mean SD 2, SD 4, or precision 4.
- **log base** → in stats and ML, log is the natural log (nats); information theory often uses log₂ (bits; 1 bit = 0.693 nats); dose–response work often uses log₁₀; R's log() is natural.
- **~ and ≈** → y ~ N(μ, σ²) is "y is distributed as"; y ~ x in R is a model formula; aₙ ~ bₙ in asymptotics means the ratio goes to 1; ≈ is a plain numeric approximation.
- **∝** → drop only factors that do not contain the variable you study: p(θ | y) ∝ p(y | θ)p(θ) drops p(y), which has no θ; dropping a θ term changes the answer.
- **argmax vs max** → max is the best value, argmax is where it happens (lowest CV error vs lambda.min); argmax can be a set when there are ties; argmin of a loss = argmax of a log-likelihood.
- **Bold, rows, columns** → many papers skip bold; vectors are columns by default, so xᵀβ is a number but xβᵀ is a matrix; MML §5.2 writes the gradient as a row vector, PML1 §7.8.2 as a column; check shapes at every product.
- **E with no subscript** → always ask "average over what?"; in VI, E_q[·] (over the approximation) and E_p[·] (over the posterior) are different numbers.
- **REML across fixed effects** → REML log-likelihoods are not comparable when the fixed effects differ; refit with ML; lme4's anova() does this by default (refit = TRUE).
- **Wald on a variance** → a z test or Wald CI for a variance near 0 is invalid (boundary, skew); use a profile CI, the mixture LR test, or a parametric bootstrap (RLRsim, pbkrtest in GLMM FAQ).
