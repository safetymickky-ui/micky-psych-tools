## Anchors

- Neuron → logistic regression. Breaks: hidden weights are not identifiable (swap two units and the fit is the same), so never read a weight like an odds ratio; no standard errors.
- Hidden layer → hand-built features (interactions, spline knots) in X. Breaks: the net learns the features; the loss surface is non-convex, so different random seeds give different weights with similar loss.
- Cross-entropy / MSE loss → NLL of a Bernoulli / multinomial / Gaussian (fixed σ) model. Breaks: training stops by validation, not at the maximum; no Hessian-based CIs.
- Gradient descent → iterative MLE (Newton/IRLS). Breaks: first-order only, noisy mini-batches, no convergence test; the learning rate is a tuned hyperparameter.
- Weight decay → ridge (Gaussian prior, MAP). Breaks: PyTorch decays biases too unless you exclude them; with Adam, L2 in the loss ≠ decoupled decay (AdamW); λ scales differ from glmnet.
- Early stopping → shrinkage tuned on validation data; equal to L2 only for a linear model with squared loss (DLB 7.8). Breaks: approximate in deep nets.
- BatchNorm / LayerNorm → z-scoring predictors. Breaks: done on hidden units at every step, with learnable γ (scale) and β (shift); BatchNorm uses batch statistics in training and running averages in eval.
- Momentum / Adam → exponential moving average, as in Rescorla–Wagner. Breaks: the "reward" is a gradient vector; Adam also divides by an EMA of squared gradients, so each weight gets its own step size.
- Dropout → bagging / ensemble averaging. Breaks: the members share weights and train together; at test time one full network replaces the average.
- CNN weight sharing → complete pooling of a coefficient across positions; receptive field → visual-system receptive fields. Breaks: CNN "pooling" layers are a different idea (downsampling); CNN receptive fields have fixed geometry and no feedback.
- RNN / LSTM → Rescorla–Wagner value carried over trials; forget and input gates → a learning rate that changes with each input. Breaks: the state is a vector and the update rule is learned and nonlinear.
- Embedding → dummy coding replaced by a learned dense vector per category, like a multi-dimensional random effect. Breaks: no shrinkage to a distribution unless weight decay is on; single axes have no fixed meaning, only distances and directions do.
- Attention weights and sampling temperature → softmax choice rule (scores ≈ Q-values; 1/√d_k and 1/T act like β). Breaks: attention chooses nothing; it outputs a weighted average and stays differentiable.
- Pretraining → MLE of a next-token model; fine-tuning → shrinkage toward the pretrained weights; RLHF → RL with the LLM as policy plus a KL penalty to the SFT model. Breaks: the "prior" is informal (small learning rate, few steps, LoRA's low rank), not a stated distribution.
- Autoencoder → PCA (a linear AE with MSE spans the PCA subspace); VAE → Bayesian latent-variable model with a KL term to an N(0, 1) prior. Breaks: nonlinear AE axes are not ordered by variance or orthogonal; the VAE posterior is only approximate.

## Common errors and term collisions

- "pooling" (dl-6.2, dl-6.3, dl-9.3): statistics = combining data or estimates across groups; CNN = max/average downsampling; GNN = summing or averaging neighbours; d2l 11.2 "attention pooling" = a weighted average. Name which one.
- "bias" (dl-1.1): b is the intercept, not statistical bias; "inductive bias" means the assumptions built into an architecture.
- "normalization" (dl-5.5): the Keras `Normalization` layer is a z-score with mean and variance learned by `adapt()`, not min–max scaling; scikit-learn `Normalizer` rescales each row to length 1; BatchNorm/LayerNorm z-score inside the net.
- Notation (dl-2.1, dl-7.1): W⁽ˡ⁾ means layer l, not a power; h_t means time step t; a prime (h′, s′, a′) means "next" or "another", not a derivative; but in 0.25¹⁰ or 10000^(2i/d) the superscript is a power.
- "β" (dl-1.2, dl-5.2, dl-5.5, dl-9.2): regression coefficient, RL inverse temperature, Adam's decay rates β₁ and β₂, BatchNorm's shift, β-VAE's KL weight: five different things.
- "logits" (dl-3.2): any pre-softmax score; it equals log-odds only in the binary sigmoid case.
- "convolution" (dl-6.1): DL layers compute cross-correlation (no kernel flip): x = [1, 2, 3, 4, 5] with kernel [1, 0, −1] gives [−2, −2, −2], while `np.convolve` gives [2, 2, 2]; "kernel" means filter weights, not a density or SVM kernel.
- "residual" (dl-6.5): a residual connection y = x + F(x) is not a regression residual y − ŷ.
- "validation" (dl-5.6, dl-9.4): the DL "validation set" is a tuning set inside development; clinical "external validation" means a new site or time. Never tune epochs, λ or T on the test set.
- Softmax before the loss (dl-3.2): `nn.CrossEntropyLoss` and `nn.BCEWithLogitsLoss` take raw logits; applying softmax or sigmoid first squashes twice and trains badly.
- Missing `model.eval()` (dl-5.4, dl-5.5): dropout stays on and BatchNorm keeps using batch statistics at test time, so predictions are noisy and wrong.
- Shapes (dl-2.1): textbooks write Wx with column vectors; PyTorch `nn.Linear` stores W as (out, in) and computes xWᵀ + b with one row per sample. Print shapes.
- Universal approximation (dl-2.3): "can represent" is not "can learn from your n", and not "will generalize".
- Attention as explanation (dl-8.2): whether attention weights explain predictions is contested; do not report them as feature importance without a separate check, such as masking the input.
- "Deep nets are overconfident" (dl-9.7): shown for 2017-era CNNs; a 2021 re-analysis found recent non-convolutional models among the best calibrated, so measure calibration on local data and recheck after shift. Temperature scaling (after training) is not sampling temperature (dl-8.9).
