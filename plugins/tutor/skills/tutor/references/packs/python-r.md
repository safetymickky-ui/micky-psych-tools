## Anchors

- ndarray of shape (n, p) → design matrix X. Breaks: shape (n,) is neither a row nor a column vector; arrays can be 3-D (patient × day × sensor); there are no column names until pandas adds labels.
- Broadcasting → centering X by column means. Breaks: R recycles a short vector silently (`c(1, 2, 3, 4) + c(10, 20)` → `11 22 13 24`); NumPy refuses unless an axis is 1, yet (n,) with (n, 1) silently gives n × n.
- Views → aliasing, two labels on one file. Breaks: slices share memory but masks and index lists copy; in pandas 3, Copy-on-Write makes every derived object behave as a copy.
- pandas index alignment → SQL join on patient ID. Breaks: it runs silently inside `+` and assignment; unmatched labels become NaN with no warning.
- groupby().transform and Polars `.over()` → person-mean centering for within/between effects in mixed models. Breaks: the math is the same, but pandas sorts group keys by default, while Polars `group_by` does not guarantee group order.
- Pipeline → a fitted model that carries its own preprocessing, as an rms fit stores its spline knots so new data are coded the same way. Breaks: only steps inside the Pipeline are refit per fold; edits made to the DataFrame before CV still leak.
- LogisticRegression `C` → ridge λ (C ≈ 1/λ; larger C = weaker penalty). Breaks: the docs say regularization is on by default, unlike glm; the penalty acts on the raw coefficient scale, so scale features first; `C=np.inf` reproduces glm (slope 2.31 in py-4.1).
- Log loss → cross-entropy H(p, q) = H(p) + KL(p‖q); minimizing it is Bernoulli MLE. Breaks: one confident wrong prediction can dominate the mean; Brier and log loss mix calibration with discrimination.
- Boosting → Rescorla–Wagner, V ← V + α(outcome − V). Breaks: the error is y − p but the update is on the log-odds scale; each step is a tree that gives one correction per leaf, computed from gradient and Hessian as −G/(H + λ), so `reg_lambda` shrinks it like ridge; too many steps overfit, so stop early on held-out data.
- `optimize.minimize` → MLE; diagonal of `res.hess_inv` → squared standard errors (inverse observed information). Breaks: with BFGS, `hess_inv` is only an approximation (SciPy docs): 1.152 vs the exact 1.155 for py-6.2's data, and the gap can be larger; check against glm or compute the Hessian before reporting SEs.
- R formula `y ~ x + (1 | id)` → R builds X and Z for you. Breaks: scikit-learn wants a numeric X that you build yourself (ColumnTransformer), and OneHotEncoder keeps all levels (no reference level) unless `drop="first"`.
- Figure/Axes → a journal figure and its panels. Breaks: `plt.*` calls act on a hidden "current" Axes; in multi-panel code, call `ax.*`.
- Virtual environment → each ward's own drug cupboard. Breaks: activation changes only the current terminal; `python -m pip install ...` installs into the Python you will actually run.
- git commit → a dated, signed chart entry (add, never erase). Breaks: history can be rewritten (rebase, force-push), so avoid that on shared branches; a file deleted later still sits in old commits.
- pytest test → lab QC with a control sample of known value. Breaks: a passing test checks the code, not the data or the model's validity.

## Common errors and term collisions

- `axis=0` means "collapse the rows" (one result per column), not "do it per row".
- (n,) minus (n, 1) gives an (n, n) array with no error → `assert y.shape == yhat.shape`; flatten with `.ravel()`.
- `b = a` is not a copy; NumPy slices are views, while masks and index lists are copies → call `.copy()` when you need an independent array.
- Chained assignment `df[df["a"] > 1]["b"] = 5` changes nothing in pandas 3 (ChainedAssignmentError warning) → `df.loc[df["a"] > 1, "b"] = 5`.
- `0.1 + 0.2 == 0.3` is False → `np.isclose` or `pytest.approx`; assigning 2.7 into an integer array stores 2.
- Off-by-one: `range(1, 9)` stops at 8, so PHQ-9 items need `range(1, 10)`; `.loc["a":"c"]` includes "c", but `.iloc[0:2]` excludes position 2.
- Missing-data defaults differ: pandas reductions skip NaN; R's `mean()` returns NA unless `na.rm = TRUE`; Polars skips null, but NaN propagates.
- Merging on duplicate keys multiplies rows (2 × 2 = 4) → pass `validate="one_to_one"` or `"many_to_one"`, and compare `len()` before and after.
- Leakage: a scaler, imputer, or feature selector fitted on all data before CV; visits of one patient in both train and test → Pipeline + GroupKFold.
- `predict()` returns 0/1 at a 0.5 cut-off, and `.score()` and default `cross_val_score` report accuracy → use `predict_proba(X)[:, 1]` and `scoring="roc_auc"`.
- Penalty names collide: LogisticRegression `C` = inverse strength; sklearn Ridge/Lasso `alpha` = strength; glmnet `alpha` = L1/L2 mix (sklearn `l1_ratio`) and glmnet `lambda` = strength; LightGBM `reg_alpha`/`reg_lambda` and XGBoost `alpha`/`lambda` = L1/L2 on leaf values.
- "transform" collides: sklearn `.transform()` applies fitted preprocessing; pandas `groupby().transform()` sends a group result back to every row.
- "index" collides: pandas index = row labels; SQL index = a lookup structure; Polars has no index, and its `group_by` output order is not guaranteed → sort, or pass `maintain_order=True`.
- R vs Python: R `x[-1]` drops the first element, while Python `x[-1]` is the last element; R `x[0]` returns an empty vector with no error.
- AI-written code often targets older library versions: scikit-learn 1.8+ deprecates `LogisticRegression(penalty=...)` (use `l1_ratio`, or `C=np.inf` for no penalty); LightGBM 4.7 deprecates `fit(eval_set=...)` (use `eval_X`, `eval_y`); pandas 3 text columns are `str`, so `dtype == object` is False; NumPy 2 prints a plain 2.0 as `np.float64(2.0)`.
